## Question and matched comparison

Does exposing M4's action refinement to multiple prediction horizons reduce
adaptive-control failures, beyond the effect of an equal amount of additional
horizon-8 training?

The original action path trained only with h8. Its separate teacher-forced JEPA
objective already used horizons 2/4/8/16/32. The diagnostic supports control
sensitivity in selected failures; it does not establish that training mismatch
explains the population regression or that this continuation will repair it.

| Setting | H8 continuation | Mixed-horizon continuation |
| --- | --- | --- |
| Initial weights | Accepted M4 epoch-2 action export and full trained predictor | Identical |
| Candidate future used for action refinement | h8 at every anchor | One of 2/4/8/16/32 per anchor |
| Exposure | Same 2,000 logical batches, in the same order | Identical |
| Action and auxiliary losses | Inherited M4 objectives and weights | Identical |
| Trainable parameters and optimizer | Same four parameter groups and schedule | Identical |
| Event predictor | Frozen; excluded from training | Identical |

Keep the unmodified M4 checkpoint as a third, non-trained reference. Train all
four existing groups (head/state, LoRA, complete future predictor, coupling),
98,859,527 parameters in each arm. Base weights and JEPA teacher stay frozen.
This tests multi-horizon exposure across the existing trainable action system;
it is not a coupling-only attribution experiment.

## Data, horizon assignment and endpoint

Use the first 2,000 unchanged batches of the original epoch-0 mixed training
plan (seed 17), reproduced against its original digest. This prefix has
**58,172 action presentations, 277,172 valid auxiliary pairs, 399 episodes and
all 40 training tasks**. Preserve short batches, normalizers, image orientation,
and the original order. This is additional exposure to existing training data,
not new or held-out demonstrations. Log inherited 117,132 updates separately
from continuation updates 0–2,000.

For the mixed arm, each consecutive group of five presentation ordinals gets
one of each horizon, permuted by SHA256 of the fixed schedule ID, seed, block
and horizon. The sealed helper defines the exact ordering. The committed sample
count supplies the cursor across batch boundaries and resume. This assignment
uses no global RNG, labels, target masks, model outputs or episode outcomes.
The full stream contains 11,635 h4 and h32 presentations each, and 11,634 each
at h2/h8/h16. Balance is a simple coverage choice, not a fitted approximation
to the observed event forecasts. No horizon-mixture search is planned.

Each anchor still receives one candidate future and one action refinement.
Keep candidate microbatch 10, complete logical-batch auxiliary backward and
the shared FP32 feature boundary. The executable proposal remains detached,
eight actions long and zero-padded through step 31. Short horizons retain the
existing prefix mask; horizons 16/32 retain padded actions. Neither prediction
nor execution length changes. Missing future targets must not remove anchors
or change candidate horizons. In particular, the candidate branch is never
supervised against a future generated by different demonstrated actions.

Use fresh AdamW optimizer/scheduler states in both arms, with peak learning rate
**1e-5 in every group**, betas (0.9, 0.95), epsilon 1e-8, weight decay 0.01 and
global gradient clip 1. Use 40 warmup updates, cosine decay to 0.1 of peak over
2,000 updates, matching the existing scheduler's update convention. The lower
peak equals the original run's terminal learning-rate scale; it is a prospective
continuation choice, not a tuned result. Reset training RNG to seed 17 after
checkpoint loading. No optimizer moments from the original run are restored.

Keep final-action all-action L1 plus 1.5140534185764003 times the original JEPA
cosine-plus-10-times teacher-relative-variance loss. No extra consistency loss,
event loss, proposal loss, confidence threshold or routing gate is introduced.
Evaluate only the fixed 2,000-update endpoints, after both arms complete.
Infrastructure checkpoints are for recovery, not selection. No pilot-dependent
extension, learning-rate sweep or early checkpoint search is permitted in v1.

4. Run a train-only qualification of 128 exact batches per arm from the accepted

5. Verify endpoint export/reload parity and new evaluator admission. The existing

The local planning checks exercise deterministic scheduling across short batches

it does not automatically increase budgets or shorten either training arm.

## Diagnostic evaluation and progression

Freeze the existing 27-case manifest, including seven adaptive wins, seven
adaptive losses, eight both-success and five both-failure cases. It is an
outcome-selected development screen. Do not limit evaluation to the three
recently inspected failures.

Run each of three checkpoints (original M4, H8 continuation, mixed continuation)
under each of two routes (event-running fixed8, original adaptive): **162 fresh
episodes**. Both routes execute eight actions at 20 Hz and run the same frozen
event branch. The adaptive route is the original nearest-onset mapping, not the
after-close gate. Rotate six condition positions across cases and retain the
original initial states, seeds, budgets, recorder and failure rules. Fresh
original controls avoid relying on old controls when small renderer differences
have previously changed outcomes.

Primary screen comparison: mixed/adaptive minus H8-continuation/adaptive paired
success count. Also report each model's adaptive-minus-fixed8 difference, and
the difference between those differences. Compare all four continued-policy
cells with contemporaneous original controls. Record every win and loss,
especially the seven historical adaptive wins, along with latency and horizon
frequencies. Audit identical initial inputs; later trajectory differences are
expected. Any initial-input mismatch makes the affected aggregate contrast
descriptive and prevents progression, without dropping the case or retrying
because of its outcome. Policy errors count as failures; classified infrastructure
errors retain at most the inherited one retry.

The prospective **engineering screen**, not a significance or acceptance test,
permits proposing an untouched panel only if all conditions hold:

- Mixed/adaptive has at least two more successes than each of H8/adaptive and
  original/adaptive.
- Mixed/fixed8 loses at most one success against each corresponding fixed8
  control (H8 continuation and original M4).
- The mixed model's adaptive-minus-fixed8 gap improves by at least one success
  relative to the H8 continuation's gap.
- All cases, input/integrity audits, model checks and resource limits are valid.

These thresholds make a small pilot decision reproducible; they do not establish
noninferiority or general adaptive benefit. If the screen fails, archive the
negative pilot and retain original M4-fixed. A failure at this training budget
does not rule out other training interventions. If it passes, freeze a separately
versioned, outcome-uninspected paired panel with audited prior exposure before
running it. None of the existing 27, 210, 467 or 200 previously evaluated panels
should be called untouched. Exact held-out identities and statistical criteria
are intentionally outside this pilot; no locked test is unlocked here.

## Known evidence and limits

At design time the original 2,001-episode evaluation, all recording/replay work,
the 81-episode gate comparison, three-case inspection and 12-episode causal
diagnostic are known. The original targeted and clean adaptive differences are
−6.85 and −5.00 percentage points. Gating recovers four failures and loses four
wins on the 27 cases. A single h4 chunk induces failure in targeted 356, the
initial disturbance is recoverable in targeted 1, and later adaptive motion
matters in clean 6. No positive new training result exists at this freeze.

Forecast errors are not repaired in this experiment. The event predictor's
weights, input processing and mapping stay fixed, although different robot
trajectories naturally produce different subsequent forecasts. Long-horizon
zero padding and the fixed eight-action execution cadence also remain. Preserve
the original JEPA quality-gate FAIL/research-use exception, weak event-label QA
limitations and historical source-exposure caveats. Original M4-fixed remains
the baseline until a separate, adequate evaluation supports a change.
